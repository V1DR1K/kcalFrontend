# Prototipos históricos de Vitality Peak

Esta carpeta conserva los prototipos HTML de Google Stitch, sus capturas y sus documentos de diseño. No forman parte de la aplicación React ni del bundle de producción.

`assets/vitality-api.js` es un adaptador legado cargado únicamente por estas páginas estáticas. Se conserva para que la referencia siga funcionando; el frontend actual usa `src/services/http.js`.
